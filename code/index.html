Two pieces. A pipeline that turns raw TRACE, Lehman and ICE data into bond panels, and a library that turns those panels into factors. Both are public, and both are what produced every number on this site.

TRACE data pipeline

github.com/Alexander-M-Dickerson/trace-data-pipeline processes Enhanced, Standard and 144A TRACE, with error-correction and cleaning procedures documented in the paper, and produces the daily and monthly panels on the Data page. It runs in parallel on the WRDS cloud and writes a data report for every run.

  • Stage 0, transaction-level cleaning.
  • Stage 1, the daily bond panel.
  • Stage 2, the monthly panel and its characteristics.
  • Stage 3, every exhibit in the paper, from any Stage 2 panel.

Reproducing the data needs a WRDS account and the underlying data licences. The pipeline README is the place to start, and the daily data dictionary and monthly data dictionary define every column.

PyBondLab

PyBondLab forms corporate bond portfolios, with portfolio turnover, characteristics, holding periods and transaction-cost adjustments built in. It is what sorts the 108 factors published here. 

pip install PyBondLab

Source and issues at PyBondLab on GitHub, worked examples at the PyBondLab examples. Maintained by Giulio Rossetti.

Data uncertainty

The same library measures how much a factor moves when reasonable choices in the data change - the filters, the sample, the weighting. The examples show how to run a grid of those choices and read the spread rather than a single number.
