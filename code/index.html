The code behind the data

The trace-data-pipeline turns about 0.5 billion TRACE trades into a daily panel of about 30 million rows and a monthly panel of about 2 million rows. The monthly panel has 108 characteristics, which PyBondLab sorts into factors.

TRACE data pipeline

The pipeline cleans Enhanced and 144A TRACE with the error corrections documented in Dickerson, Robotti and Rossetti (2026) and builds the daily and monthly panels on the Data page, with a data report for every run. Stages 0 and 1 run in parallel on the WRDS cloud in about five hours. Stages 2 to 4 run on your own computer in minutes. The code is at github.com/Alexander-M-Dickerson/trace-data-pipeline.

  • Stage 0 cleans the transactions, about 0.5 billion rows.
  • Stage 1 builds the daily panel, about 30 million rows with prices, credit spreads and duration.
  • Stage 2 builds the monthly panel and its characteristics.
  • Stage 3 rebuilds the tables and data figures of Dickerson, Robotti and Rossetti (2026) in about 18 minutes.
  • Stage 4 builds the TRACE-only bond factors shown in FactorViz and checks them against the published files.

Reproducing the data needs a WRDS account and the data licences. Start with the trace-data-pipeline README. The daily data dictionary and the monthly data dictionary define every variable the pipeline produces.

PyBondLab

PyBondLab forms corporate bond portfolios and computes their turnover and characteristics, for any holding period and with cost-reducing rules such as banding and staggered rebalancing. The 108 factors on this site are built with it. 

pip install PyBondLab

PyBondLab installs on Python 3.11 or 3.12. The pipeline README shows how to install it beside the pipeline on newer versions. See the worked examples on GitHub. Giulio Rossetti maintains the package.

Data uncertainty

PyBondLab also measures how much a factor changes when reasonable choices about the data or the sort method change, for example through the non-standard error. The examples on PyPI show how to run these checks.
